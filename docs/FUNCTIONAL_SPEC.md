# 2026 해양수도 부산 AI 창업 경진대회 참가관리 기능명세서

승인일: 2026-08-25

## 범위

- 기존 랜딩페이지 행사 정보는 유지하며 신청 화면에는 공통 헤더와 행사명만 표시한다.
- 참가자는 팀 단위 신청, 접수번호 확인, 팀명·비밀번호 인증 후 본인 신청 조회·수정을 할 수 있다.
- 관리자는 Supabase Auth로 인증하고 신청 관리, 상태 변경, 비밀번호 초기화, 운영 설정, 감사 이력, 엑셀 처리를 수행한다.
- 신청 완료 이메일만 발송한다. 수정·초기화·관리자 알림 이메일은 발송하지 않는다.

## 신청 항목

팀명, 신청 비밀번호/확인, 대표자 이름·이메일·연락처, 참가 유형, 9대 전략산업 참가 분야, 아이템명·요약, 대표자 포함 2~4명 팀원 이름·역할, 부산 소재 여부, 참가 자격 확인, 지원 제외 대상 확인, 개인정보 동의, 선택 요청사항을 받는다.

생년월일, 주소, 사업자 정보, 사업계획서, 팀원별 연락처, 부산 소재 증빙은 확정 전까지 받지 않는다. 참가자 사진은 받지 않는다.

## 미확정 설정

- 아이템 요약 제한값이 없으면 시스템 안전 상한 10,000자만 적용한다.
- 증빙 종류·최대 개수·파일당 용량이 모두 설정되기 전에는 업로드 UI를 표시하지 않는다.
- 네이버 SMTP 발신 설정이 없으면 신청은 접수하고 이메일 로그를 `configuration_missing`으로 기록한다.
- 개인정보 자동 삭제와 감사 로그 자동 삭제는 보관기간 확정 전까지 수행하지 않는다.

## 보안 및 운영

- 팀명은 NFKC, 공백 정리, 영문 대소문자 무시 후 고유값으로 저장하며 표시 원본을 보존한다.
- 신청 비밀번호는 bcrypt 비용 12로 해시하며 원문을 저장하거나 기록하지 않는다.
- 로그인 실패 시 팀명과 비밀번호 중 어느 값이 잘못됐는지 구분하지 않는 동일한 메시지를 표시한다.
- 브라우저 직접 DB 접근은 RLS와 권한 회수로 차단하고 검증된 서버 API만 서비스 역할 키를 사용한다.
- 증빙은 비공개 버킷에 저장하고 10분 서명 URL로만 제공한다.
- DB 시간은 UTC, 화면 입력·표시는 Asia/Seoul을 사용한다.
- 상태는 접수완료, 검토중, 보완요청, 예선통과, 예선탈락, 본선수상, 최종탈락, 접수취소만 허용한다.

## 엑셀

승인된 17개 열과 순서를 고정한다. 다운로드는 전체·검색결과·선택 항목을 지원하며 업로드는 기존 접수번호의 수정만 허용한다. 행별 검증과 변경 미리보기 후 관리자 확인 때만 반영하며 결과를 감사 로그에 남긴다.
